# SageCards

Digital business cards, reimagined. One tap — share who you are.

## Stack
- **Web**: Next.js 15 (App Router), React 19, TypeScript, Tailwind v4, shadcn/ui
- **App**: NestJS, Mongoose, MongoDB Atlas
- **Auth**: Better-Auth
- **Monorepo**: Bun workspaces + Turborepo

See `docs/architecture.md` and `docs/plans/PHASE-0.md` to start.
